# Gesture Canvas AI

Python | OpenCV | MediaPipe | CVZone | NumPy

A gesture-controlled virtual drawing application using Python, OpenCV, MediaPipe and CVZone.


The project allows users to draw in the air using hand gestures detected through a webcam. Users can select colors, adjust brush sizes, erase drawings, save their work, and undo mistakes without using a physical drawing device.

## Installation

Clone the repository:

```bash
git clone https://github.com/Addwit0106/Gesture-Canvas-AI.git
```

Navigate to the project folder:

```bash
cd Gesture-Canvas-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

---

## Controls

| Action            | Control               |
| ----------------- | --------------------- |
| Draw              | Index Finger Up       |
| Toolbar Selection | Index + Middle Finger |
| Hide Toolbar      | Fist                  |
| Palm Eraser       | Open Palm             |
| Save Drawing      | S Key                 |
| Undo Last Stroke  | U Key                 |
| Quit Application  | Q Key                 |
